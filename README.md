## 🔧 How It Works

TripDeck uses a web-based setup with a server and a browser view. You do not need to manage that part if you only want to run the app.

The app is built with:
- ASP.NET MVC for page structure
- Razor Pages for page rendering
- JavaScript for page interaction
- jQuery Ajax for content updates
